
# Bài 2 - Phần 2: HTTP Server đầu tiên

## 1. Giới thiệu
Xây dựng ứng dụng Node.js sử dụng module HTTP.
Server chạy tại cổng 3000 và trả về trang HTML
hiển thị thông tin sinh viên.

## 2. Thông tin sinh viên
- Họ và tên: Nguyễn Đức Dưỡng
- Mã sinh viên: CĐ-CNTT18B06

## 3. Công nghệ sử dụng
- Node.js
- Module http
- HTML
- CSS

## 4. Cách chạy chương trình

Bước 1: Cài đặt Node.js.

Bước 2: Mở thư mục bài tập bằng VS Code.

Bước 3: Mở Terminal và chạy lệnh:

node myFirstNode.js

Bước 4: Mở trình duyệt và truy cập:

http://localhost:3000

## 5. Kết quả
Trang chủ hiển thị thông tin sinh viên
khi truy cập vào địa chỉ localhost:3000.
